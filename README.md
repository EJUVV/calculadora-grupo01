# Calculadora EJUVV

## Sobre o projeto

Calculadora desenvolvida com HTML, CSS e JavaScript como atividade prática da EJUVV.

## Funcionalidades

- Adição, subtração, multiplicação e divisão.
- Utilização dos botões da interface e do teclado.
- Limpeza do visor.
- Remoção do último caractere digitado.
- Limite de caracteres no visor.
- Exibição do resultado das operações.
- Tratamento de expressões inválidas.
- Interface responsiva.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Git e GitHub

## Como executar

1. Clone ou baixe este repositório.
2. Abra a pasta do projeto.
3. Execute o arquivo `index.html` em um navegador.
4. Utilize os botões ou o teclado para realizar os cálculos.
